Per stage: compute share of the step and device memory (VRAM)

Compute share = the median, over the stage's GCDs, of the last step's time spent outside collective calls (step time minus the time inside all-to-all, all-reduce and pipeline send/receive, timed by the heartbeat hooks). VRAM = the device memory used on the stage's fullest GCD, its peak since the attempt started (rocm-smi used / total, sampled every 1-3 minutes by the job's monitor); dashed tick = the most memory PyTorch allocated on the stage this attempt, read from the heartbeats (a part of the VRAM); grey tick = the memory model's predicted VRAM; the bar ends at the 64 GiB of a GCD, the real limit.
